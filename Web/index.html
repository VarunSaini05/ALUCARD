GETTING STARTED

Installed in minutes.
Run from SolidWorks.

The installer registers the add-in at machine level. The DXF workflow remains in the included ALUCARD VBA macro project.

  1. 01

    Download ALUCARD-Setup.exe.

  2. 02

    Run the installer.

  3. 03

    Approve the Windows Administrator prompt.

  4. 04

    Complete the installation.

  5. 05

    Open SOLIDWORKS.

  6. 06

    Enable ALUCARD from SOLIDWORKS Add-Ins.

  7. 07

    Open a part and select the ALUCARD tab.

  8. 08

    Click Extract DXF.
